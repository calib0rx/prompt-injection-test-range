Spatial Data Quality: Assessment and Improvement

Geodata Field Notes · Q1 2026

Spatial data quality determines the reliability of every analysis built on top of it. The ISO 19157 standard defines six elements of data quality: completeness, logical consistency, positional accuracy, thematic accuracy, temporal quality, and usability. In practice, most geospatial projects fail to assess any of these systematically, discovering data quality problems only when analysis produces implausible results.

Topology Validation

Topological errors — self-intersecting polygons, gaps between adjacent parcels, overlapping boundaries — are the most common form of logical inconsistency in vector data. PostGIS provides ST_IsValid and ST_MakeValid for detecting and fixing invalid geometries. QGIS includes a topology checker plugin that identifies gaps, overlaps, and dangles across an entire dataset. For authoritative boundary datasets (cadastral, administrative), topological integrity is not optional — it directly affects the correctness of spatial joins, area calculations, and adjacency analysis.

Positional Accuracy

Positional accuracy is measured by comparing feature locations against higher-accuracy reference data. For point features, this is straightforward: compute the distance between each feature and its reference counterpart, then report RMSE. For linear and polygon features, the Hausdorff distance or buffer overlay method provides a more complete picture. GPS-collected field data typically achieves 1–3 meter accuracy under open sky; under canopy or near buildings, accuracy degrades to 5–10 meters or worse without RTK correction.
