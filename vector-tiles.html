Vector Tile Pipelines for Web Mapping

Geodata Field Notes · March 2026

Vector tiles have largely replaced raster tiles for interactive web maps. By encoding geometry and attributes as protocol buffers organized into a tile pyramid, vector tiles enable client-side styling, smooth zoom transitions, and dramatically reduced storage requirements compared to pre-rendered raster imagery.

Tippecanoe and Tile Generation

Mapbox's Tippecanoe remains the standard tool for generating vector tilesets from GeoJSON input. Its key strength is intelligent feature simplification and dropping at lower zoom levels — it uses algorithms that preserve visually important features while reducing tile size. The --minimum-zoom, --maximum-zoom, and --drop-densest-as-needed flags control the trade-off between detail and performance. For planet-scale datasets, tile generation can take hours; parallelizing with GNU parallel or running on large EC2 instances is common.

Serving Tiles

PMTiles is a cloud-native tile archive format that stores an entire tileset in a single file on S3 or similar object storage. The client uses HTTP range requests to fetch individual tiles, eliminating the need for a tile server. For higher-traffic applications, Martin (Rust-based) and pg_tileserv (PostGIS-native) generate tiles on the fly from database queries, trading compute cost for the ability to serve always-current data without a batch tile generation step.

Styling with MapLibre

MapLibre GL JS is the open-source fork of Mapbox GL JS that has become the default renderer for custom vector tile maps. Styles are defined in a JSON specification that controls layer visibility, color ramps, label placement, and zoom-dependent rendering. The style spec is powerful but verbose — most teams maintain a base style and override layers per application rather than writing styles from scratch.
